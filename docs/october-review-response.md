# moonsize 复审补充说明

针对“保守引用图及逐段压缩模型不足以支撑精确删减收益的承诺，请说明 retained size 与实际重编译减量、整流传输成本的边界并附带案例”，我们撤回原材料中的精确删减与网络份额承诺。修订后的定位是：定位体积来源、解释模型引用、比较实际构建、阻止 CI 回归。

| 问题 | 当前准确承诺与证据 |
| --- | --- |
| retained 是否等于删除收益 | 固定图与根集合下支配子树中的可达本地函数编码权重，包含长度前缀；不模拟调用者改写、数据/名称变化、编译优化或索引重编号，不提供重编译收益的通用上下界。 |
| 不可达是否安全删除 | 仅为当前模型内的调查候选。element 函数作为保守根；已识别引用调用、动态表等缺口会诊断。strict 通过也不证明完全建模或精确收益。 |
| 引入路径是否实际执行 | 确定性最短模型引用路径，保留根来源、边类型、实际 opcode 与偏移；零步保守根、指定入口未找到、搜索限额与图缺口分别说明。 |
| 独立 gzip 是否网络贡献 | 逐段/逐函数单独压缩，只反映局部可压缩性；不可相加为整文件，也不表示传输份额。 |
| 整文件 gzip 是否传输成本 | 指定压缩器配置下完整文件作为一个流的表示体测量。部署可能使用其他编码或不压缩；未测 HTTP/TLS 开销、缓存或实际传输。 |

## 真实重编译案例

固定工具链 moon 0.1.20260915 / moonc v0.10.13+cbb11c36f、Windows x64、wasm/debug/no-strip 的已记录样例：

| 源码变化 | 模型 retained | 完整 Wasm 减量 | 整文件 gzip 减量 |
| --- | ---: | ---: | ---: |
| 移除可选分支及独占字符串 | 52 B | 656 B | 237 B |
| 移除可选调用，共享依赖保留 | 16 B | 127 B | 41 B |

这些是固定样例值，非普遍比例。release 模式也运行同一流程，gzip 减量为 228/39 B。独占 debug 样例的独立段 gzip 合计为 5371 B，完整流为 5236 B，显示非可加性；不能据此建立对所有文件的大小不等式。共享案例确认 shared 在 after 仍存在，不把共享函数归为 target 的独占减量。

脚本真实执行 before → after → rollback；两侧使用相同工程路径、工具链和参数，保存源码/产物 SHA-256、输出、图与实验报告。**案例有意移除了可选输出**，基础输出保持且回退恢复完整产物和原输出；这不是完整业务行为等价证明。文件变小也不自动证明修改正确。人工编码 table 对照另行标注，不能冒充 MoonBit 重编译案例。
